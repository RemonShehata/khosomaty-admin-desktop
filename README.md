The icon colour tells you which one you are in: **blue** = live, **red** = staging, **green** = debug.
All three can be installed side by side.

## First open

The installers are not code-signed yet, so the system warns once:

- **Windows:** "Windows protected your PC" → **More info** → **Run anyway**.
- **macOS:** open the .dmg, drag the app to Applications, open it. When macOS refuses, go to
  **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.
